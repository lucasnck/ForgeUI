  ComponentOpenProps,

  onClick(event: MouseEvent<HTMLDialogElement>): void;
  onCancel(event: SyntheticEvent<HTMLDialogElement>): void;

## Criteria

- [x] closeOnOutsideClick defaults to false. When enabled, a primary click beginning and ending outside native dialog bounds requests onOpenChange(false); inside clicks, drag across bounds, canceled pointers, caller-prevented events and nested dialog events do not dismiss. Controlled refusal keeps the dialog open; accepted close restores focus through the existing lifecycle. The option is not forwarded to the DOM.

- [x] Each shared declaration has one canonical owner and remains exported through @/design-system.

- [x] V2 typed usage fixtures cover Dialog, AlertDialog, useModal: Native modal refs, initial/return focus and controlled open requests. Include an accepted public consumption and a rejected unsupported value/shape for each relevant union/interface boundary, using the actual source types rather than a second local declaration.
- [x] V2 typed fixtures identify this canonical source; any existing consuming Properties/Contract references the same owner; native inherited members remain delegated and repeated fixture labels keep stable one-based identity where applicable. Types have no invented runtime methods, independent visual page or new resource kind. The accepted and rejected consumer fixtures use the available canonical exports.
