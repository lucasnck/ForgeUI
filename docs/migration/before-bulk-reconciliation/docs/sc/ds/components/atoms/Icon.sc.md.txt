## Content

```tsx
import type { ReactElement, SVGProps } from "react";
import type {
  ComponentIconSize,
} from "../../../types/icon";
import type { IconName } from "../../../types/icon-geometry";
import { iconData } from "../../../helpers/icon-data.generated";
import styles from "./Icon.module.css";

export interface IconProps extends SVGProps<SVGSVGElement> {
  name: IconName;
  size?: ComponentIconSize;
  label?: string;
}

export function Icon({
  name,
  size,
  label,
  className,
  ...props
}: IconProps): ReactElement {
  const geometry = iconData[name];
  const presentation =
    geometry.drawing === "stroke"
      ? {
          fill: "none",
          stroke: "currentColor",
          strokeLinecap: "round" as const,
          strokeLinejoin: "round" as const,
        }
      : { fill: "currentColor" };

  return (
    <svg
      {...props}
      {...presentation}
      viewBox={geometry.viewBox}
      className={[styles.root, className].filter(Boolean).join(" ")}
      data-icon-size={size}
      role={label ? "img" : undefined}
      aria-label={label}
      aria-hidden={label ? undefined : true}
      focusable="false"
    >
      {geometry.paths.map((d) => (
        <path key={d} d={d} />
      ))}
    </svg>
  );
}
```

## Criteria

- [x] Given a name, the rendered `svg` carries that geometry's `viewBox` and one `path` per geometry entry, in order.
- [x] Given no `label`, the icon renders `aria-hidden="true"`, `focusable="false"` and no role; given a `label`, it renders `role="img"` with that name and no `aria-hidden`.
- [x] Given each `ComponentIconSize` value, `data-icon-size` matches and the recipe resolves the corresponding length or `1em`.
- [x] Given a `stroke` geometry, the rendered presentation is `fill="none"` with `currentColor` stroke and round caps and joins; given a `filled` geometry, it is `fill="currentColor"`.
- [x] Given a `className` or native SVG attribute, it is forwarded and appended without replacing the recipe classes.
- [x] Given a filled or colored parent, the icon follows the inherited color in all four themes and forced colors.
- [x] Given the component source, no icon vendor, package name or upstream icon name appears.
- [x] Given the delivery, `npm run lint`, `npm run test:contracts`, `npm run test:tokens`, `npm run test:design-system` and `npm run build` pass.
- [x] Includes the drawing-model application (`stroke` or `filled`), the size attribute contract and native SVG attribute passthrough.
- [x] Excludes geometry, naming and provenance ([Icon sources](../../helpers/tech-icon-sources.sc.md)), multi-color, duotone and illustrated assets, icon-only controls and their labelling (future `IconButton`), animated icons, and any consumer-specific meaning such as error or required state.
- [x] The component has no knowledge of the adopted icon source: it renders `IconName` and `IconGeometry`, so replacing the source does not touch this file.
- [x] The name contract uses Required; `IconName` from the generated data; unknown names are a type error.
- [x] The label contract uses undefined; Localized accessible name for a meaningful icon; absent means decorative.
- [x] The Native SVG attributes contract uses Native contract; `className`, `data-*`, event handlers and `aria-*` pass through; color declarations do not.
- [x] `size` is not a native SVG attribute, so it does not conflict with the inherited `SVGProps` surface.
- [x] `width` and `height` remain accepted as native attributes but are never rendered by the component itself; a caller that passes them overrides the recipe intentionally.
- [x] `focusable="false"` keeps the icon out of the tab order in engines that still make SVG focusable.
- [x] Component-local CSS: `src/design-system/components/atoms/Icon/Icon.module.css`.
- [x] The module declares no size, alignment, stroke, color or vendor-specific rule; all of it comes from the shared recipe and its tokens.
- [x] Native Option and pure layout/text primitives do not receive an invented animation axis.
