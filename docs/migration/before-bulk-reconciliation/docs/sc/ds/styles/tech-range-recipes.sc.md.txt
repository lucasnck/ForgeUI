## Criteria

- [x] Normalized native values and accessible names remain available independently of the decorative SVG track and its motion.
- [x] User-authorized renderer revision: native progress/meter retain their normalized data and accessible names inside VisuallyHidden. A private RangeTrack SVG provides the visible filled track independently of browser-native pseudo-elements. All three public range consumers extend existing ComponentAnimatedProps (default true); numeric widths are SVG geometry data, never inline CSS. Transition uses --motion-normal/--ease-standard; indeterminate Progress uses --motion-pulse-duration/--ease-linear. No delayed semantic value, fabricated task progress or component timer. Own native progress/meter adaptation, finite range normalization and one track sizing recipe. Progress measures task completion; Meter measures a scalar within a known range. No polling, timers, percent state duplication, API or feature dependency.
- [x] Track size xs/sm/md/lg/xl — height length-1/1/2/3/4; md default
- [x] Numeric range data belongs in native value/min/max attributes. Do not inject runtime CSS widths or duplicate normalized values in state.
- [x] range-components.module.css exports range, progress, meter, visual and fill. Shared size/tone/fullWidth recipes remain canonical. Wrapper uses the existing surface, border and radius tokens. SVG viewBox is 0 0 100 1, preserveAspectRatio none; rect width is the normalized ratio times 100 and height is 1. These are vector geometry attributes, not CSS style values. fill uses --control-background and transitions width via the existing motion tokens only while data-animated=true. A separate indeterminate segment has fixed geometric width 30 and a token-backed translation animation. Reduced motion disables both transition and animation. Forced colors uses the Highlight system token.
- [x] Meter ratio uses (value-min)/(max-min), with half-scaled arithmetic only when extent overflows; avoid NaN for extremely small valid ranges. One native accessible element and one decorative SVG render per component. No duplicate progressbar/meter role or native vendor styling remains. No public RangeTrack export/catalog entry.
- [x] Native thresholds stay ordered and progress/meter semantics remain distinct.
- [x] Native names, fullWidth, five sizes and seven tones use the canonical adapter and token recipes; static rendering and targeted browser integration are verified without a repeated platform certification matrix.

- [x] The preview uses actual public behavior/recipes, stable indexed fixture strings where repeated, colocated view logic and reset cleanup.
